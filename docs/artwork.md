# Launcher artwork

`ui/flight-panorama.png` is an original AI-generated illustration created for
Flightdeck with OpenAI image generation. It depicts an unbranded light aircraft
above Alpine mountains. It is not a simulator screenshot or evidence of game
performance, and is included under the launcher's MIT license.

SHA256: `f64fc375e0aaa806c4de91cd91ec8f18994a06ff64aa80d8b6d95f7c463c9304`.

## Flightdeck mark

`ui/mark.svg` is Flightdeck's pointed folded-paper plane mark. An OpenAI
image-generation concept informed the sharp rear notch and open central fold.
The final mark is hand-coded as two flat cyan SVG faces in a square view box,
without raster tracing, gradients or embedded images. The mark is included under
the launcher's MIT license and is reused by the website.

- SVG SHA256: `69da4e0f5a3f859a1fd5d29dac38e326dc6e083a7bcee881eddf7ff1f21bf58c`
- Concept PNG SHA256: `e34416fc0741cae9bf78ea2b7d02e555d631cd525e21c67dd830748c273e9884`

## Interface font

`ui/manrope-variable.woff2` is Manrope by the Manrope Project Authors, distributed
under the SIL Open Font License 1.1. The complete license and copyright are in
[`ui/OFL-Manrope.txt`](../ui/OFL-Manrope.txt).

The source is the complete variable font from
[Google Fonts commit b31870a](https://github.com/google/fonts/blob/b31870aff700ab7a1d74fa0c6887d95beb9e0037/ofl/manrope/Manrope%5Bwght%5D.ttf),
converted to WOFF2 with fontTools 4.64.0 and `recalcTimestamp=False`. Weights
200–800 and all glyphs are preserved. The launcher serves it locally.

- Original TTF SHA256: `3ae11c49db0455a3cc33e37d380f20fdb8c7f8b41dc07625c177e3d87a9d6ae6`
- WOFF2 SHA256: `30b83738add8c9edd9e3450b98036a9a8fb5668d0cbd4eb0ce5fe6761197f21f`

The source checker permits only individually reviewed binary assets by exact
checksum. Private screenshots and unreviewed files remain excluded.

## Launcher preview

Flightdeck interface with isolated example installation data. It contains no
account information or real installation paths. It demonstrates the launcher
layout, not a running simulator or proof of game compatibility. The interface
and aircraft artwork use the MIT license; the rendered font is Manrope above.
